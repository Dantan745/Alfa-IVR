# Карточка продуктового решения — Alfa Кошелёк ЦР

## 1. Решение в одном абзаце

Для молодых клиентов Альфа-Банка (18–25) выбран сценарий **первого перевода цифровым рублём**. Сейчас ЦР спрятан в большом банке, шагов много, нет раннего антифрода. Мы даём отдельный кошелёк: понятный баланс, перевод по телефону/ID за один экран, лимиты и предупреждение ML *до* отправки.

## 2. Пользователь и контекст

Студент / первый оклад, уже в Альфе, слышал про цифровой рубль, боится «сложного ЦБ-продукта». Сценарий важен банку: онбординг в ЦР, частота P2P, доверие.

## 3. Текущий путь (барьеры)

Открыть Альфа-Онлайн → найти ЦР → кошелёк/счёт → перевод → много полей и терминов → SMS после факта. Барьер: неясно, что это за деньги и безопасна ли первая операция.

## 4. Проблема и бизнес-смысл

Пользователь не совершает первое действие → нулевая конверсия в ЦР. Банк теряет вовлечение и несёт риск мошенничества «после уведомления».

## 5. Что меняется

Онбординг 3 шага; главная с балансом ЦР и быстрыми действиями; перевод с проверкой лимита и ML; QR; история; офлайн-просмотр.

## 6. Артефакт

Интерактивный Android-прототип (этот репозиторий) + user flow: Auth → Home → Transfer → History.

## 7. Ценность

Пользователь: меньше страха, понятный остаток, подсказка «это странно». Банк: конверсия в первый перевод, удержание, снижение фрода.

## 8. MVP и дальше

MVP: локальная БД, перевод, лимиты, эвристика ML, QR-генерация.  
Не в MVP: настоящий ЦР ЦБ, OAuth, TFLite, CSV с диска, камера на всех девайсах.  
Дальше: API Фариса, модель Даниила, RuStore.
